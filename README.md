# Viviana Henriques – Front-End Portfolio

This repository contains my personal front-end portfolio website.

The portfolio is designed as an interactive experience inspired by the Windows 7 desktop environment, where projects are presented as application windows and skills are displayed through a simulated system menu. The goal is to reflect not only the final work, but also how I think, structure interfaces, and approach interaction and logic in front-end development.

## Concept

Instead of a traditional scrolling website, this portfolio behaves like a workspace:
- Projects appear as draggable-style windows
- Skills are organised through a Windows-inspired menu
- Case studies open as maximized application views
- The interface prioritizes interaction, structure, and behavior over purely visual presentation

## Features
- Interactive project cards styled as Windows 7 application windows
  - cards can be closed when clicking on the minimize or close button
  - if a project card is closed, the project's icon will appear so it can be re-opened
- Dedicated case study pages for each project
- Skill section inspired by the Windows Start Menu
- Animated background built with p5.js
- Responsive layout with a bottom taskbar-style navigation
- Accessible navigation with icons and semantic labels

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- p5.js
- Git & GitHub
